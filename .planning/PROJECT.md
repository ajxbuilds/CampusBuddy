# CampusBuddy

## Overview
CampusBuddy is a comprehensive college community platform for **complaint management, complaint escalation, AI-based guidance, peer-to-peer problem solving, and gamification**.

### Philosophy
**Connect → Understand → Help → Solve → Earn Points**

## User Roles
- **Student**: File complaints, view status timelines, request escalations, ask AI for guidance, participate in community discussions, earn points and badges, view leaderboards.
- **Teacher**: Answer student questions, review and resolve assigned complaints, endorse verified solutions.
- **Parent**: Transparently monitor linked student's complaints, statuses, and resolution updates.
- **Admin**: Full complaint lifecycle management, escalation review, user role assignments, moderation, analytics charts, and audit logs.

## Stack
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide React, React Router
- **Backend**: FastAPI (Python 3.12), SQLAlchemy 2.0 Async, Pydantic v2, JWT Auth
- **Database**: PostgreSQL / SQLite (dual support)
