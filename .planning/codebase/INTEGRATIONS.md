# Integrations and External Services

## External APIs & AI Services
- **Google Gemini API**: Configured as an AI provider for dynamic guidance and the intelligent chatbot system.
- **OpenAI API**: Alternate AI provider supported for chat and procedural advice.

## Authentication & Identity
- **Google OAuth 2.0 / OIDC**: Configured to provide Single Sign-On (SSO) and authentication via Google accounts.

## External Communication
- **SMTP Email Service**: Standard SMTP server integration (e.g., Gmail SMTP) to send transactional emails, alerts, and system notifications. Validated using `email-validator`.
